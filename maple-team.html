House rules

Three laws the team lives by

Ask first, always The team never auto-engages. On a coding task the orchestrator asks “Use Maple Team for this?” — no yes, no team.
Agents can't call agents Only the main thread routes. It carries the plan to the engineer and the diff to QA — every hand-off passes through the middle.
Model is fixed at spawn An agent can't change its own brain mid-run. Need more horsepower? Route to a different agent — that's why two engineers exist.
Get started

Install in about a minute

  1. Clone the repo

    Needs bash and git. Nothing else — the agents are plain markdown.

  2. Run the installer — pick a scope

    It asks: User (~/.claude/agents, personal, every project) or Project (<repo>/.claude/agents, checked into one repo and shared with your team). Project prompts for the repo path and validates it. Either way it copies the six maple-* agents and their guide playbooks, then rewrites each guide path to suit the scope.

  3. Wire up CLAUDE.md

    Paste the block from CLAUDE-maple-team.md into your CLAUDE.md — ~/.claude/CLAUDE.md for a user install, the repo's ./CLAUDE.md for a project install — so Claude knows the team exists and how to route. The installer leaves CLAUDE.md alone on purpose — no duplicates.

  4. Restart Claude Code

    Reload so it picks up the new agent types. Then, on a coding task, say the word — the team asks before it engages.

# 1 · clone
$ git clone https://github.com/yourjhay/maple-team.git
$ cd maple-team

# 2 · install — it asks user vs project
$ ./install.sh

# 3 · paste CLAUDE-maple-team.md into
#     your CLAUDE.md, then restart.
./install.shAsk user-vs-project, then copy the agents in.
./install.sh --userUser install — ~/.claude/agents, every project.
./install.sh --project [DIR]Project install into DIR/.claude/agents; prompts for and validates the repo path if DIR is omitted.
./install.sh --dest DIRInstall into a custom agents directory.
./install.sh --linkSymlink instead of copy — local dev only, don't commit symlinks.
./install.sh --dry-runPreview every change without touching a thing.
./install.sh --uninstallRemove the installed maple-* files.
Heads up — maple-qa uses the playwright Claude Code plugin for visual / E2E review. Install that plugin if you want QA to drive a real browser; everything else works without it.
Lineage

Named for a guild of eight

Maple Team takes its name from Guild Maple Tree — the tiny guild from the anime BOFURI: I Don't Want to Get Hurt, so I'll Max Out My Defense. A handful of members, each specialized to an absurd degree, beating guilds fifty times their size through preparation and one stubborn principle: refuse to take damage.

Same philosophy here. A small roster of extreme specialists, with QA and Security as the maxed-out defense — bugs and exploits both bounce off the wall. Nothing ships that can hurt you.
